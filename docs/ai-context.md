# 未来塾アプリ プロジェクト設計図 (2026-04-04 更新)

## プロジェクト概要
- **目的**: 外国籍児童や中学受験を目指す子どものための、SRL（自己調整学習）支援プラットフォーム。
- **コア体験**: 「自分で計画し、方法を選び、時間を計測して振り返る」自走サイクルの確立。
- **ブランドカラー**: #FFFDF0 (クリーム), #FCD34D (黄), #1C1410 (墨)
- **マスコット**: 柴犬（学習のアドバイスや応援を担当）

## テックスタック
- **Frontend**: Next.js 15 (App Router), Tailwind CSS
- **Backend**: Supabase (PostgreSQL, Auth)
- **Deployment**: Vercel

## データベース構造 (主要テーブル)
1. **plans**: クエスト（タスク）管理。planned_minutes, actual_minutes で時間管理。
2. **learning_resources (NEW)**: 教材マスター。教材名とページ数で動画や解説記事を紐付け。
   - `resource_type`: 'page' (個別解説) / 'common' (公式集・単語表などの共通基礎)
3. **flashcard_books/sets/v3**: 単語学習データ。英語教材のみ中国語訳を表示する動的ロジック。

## 画面構成
### 1. 【司令塔】ホーム画面 (`/student`)
- 今日のクエストを一覧表示。進捗バーで達成感を可視化。
- タスクタップで「学習ハブ」へシームレスに遷移。

### 2. 【実行】学習ハブ (`/student/study`)
- **集中タイマー**: リアルタイムで学習時間を計測。予想vs実績のモニタリング。
- **SRLメニュー**: 「動画で見る」「解説を読む」「単語を特訓」から学習戦略を選択。
- **マスター連動**: 教材名とページ数から自動で最適なコンテンツを表示。

### 3. 【修行】単語学習 (`/flash`)
- **スマート司令塔**: スライダーとタイルUIで、迷わず学習モードを選択。
- **ならべかえクイズ**: スペルの構造をパズル感覚で学ぶ新モード。
- **一覧画面**: 赤シート（全項目対応）と音声再生機能を搭載。

### 4. 【管理】管理者画面 (`/admin`)
- **教材マスター管理**: 動画URLやMarkdown解説記事をスマホから登録・編集。
