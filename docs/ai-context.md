# 未来塾アプリ プロジェクト設計図 (2026-04-04 更新)

## プロジェクト概要
- **目的**: 自立学習（SRL）を支援する小学生向けプラットフォーム。
- **最新の進化**: 単語帳から「学習の司令塔（ハブ）」へ進化。方法の選択、時間計測、共通基礎の参照を統合。

## 学習ハブ仕様 (/student/study)
- **タイマー**: ヘッダー右上でリアルタイム計測。予想vs実績のモニタリング。
- **コンテンツ紐付け**: 教材名とページ番号で `learning_resources` テーブルから動画・解説を自動取得。
- **共通基礎 (Omamori)**: その教材でずっと使う公式や単語表を、どのページからでも参照可能。
- **画像表示**: 解説記事内に画像を埋め込み表示可能。
