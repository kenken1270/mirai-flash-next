# 未来塾アプリ プロジェクト設計図 (2026-04-05 最終更新)

## プロジェクト概要
- **目的**: 外国籍児童や中学受験生向けのSRL（自己調整学習）支援プラットフォーム。
- **コアバリュー**: 自分で計画し、方法を選び、時間を計って振り返る自走サイクルの確立。

## 完了ミッション (2026-04-04 ~ 04-05)
### 1. 【修行】単語学習の刷新
- **スマート司令塔 (/flash)**: スライダーとタイルUIによる1画面完結型UI。
- **ならべかえクイズ**: スペルの構造をパズルで学ぶ新モード。
- **英検4級 4訂版**: 127語（178〜304番）をページ準拠で完全登録。

### 2. 【実行】学習ハブの構築 (/student/study)
- **多言語スイッチ**: `[:ja][:zh]` タグによる日本語/中国語の動的切り替え。
- **集中タイマー**: リアルタイム計測と「予想vs実績」のモニタリング機能。
- **教材マスター連動**: `learning_resources` とタスクを自動紐付け。
- **画像・リンク対応**: 解説内への画像埋め込みとURL自動リンク化。

### 3. 【管理】管理者画面のリニューアル (/admin)
- **目に優しいUI**: ダークモードを廃止し、白基調のダッシュボードへ刷新。
- **階層型ライブラリ**: 左サイドに教材ツリー、右側に「ページ解説」と「共通保管庫（リンク集）」を配置。
- **編集機能**: 既存データの修正、画像・動画URLの即時更新に対応。

## データベース重要テーブル
- `plans`: タスク管理（教材名・ページ番号を含む）。
- `learning_resources`: 教材マスター。動画・画像・多言語解説を保持。
- `flashcards_v3`: 単語データ。英語教材のみ中国語訳を自動表示。
