## 安定した確認環境（このプロジェクトの決め）

- **ローカル `http://localhost:3000` は第一推奨にしない**（PC・ポート・キャッシュでブレやすい）。
- **普段の動作確認のデフォルト**は次のどちらかに統一する。
  1. **`dev` ブランチに push したあとの Vercel Preview**  
     Vercel → **Deployments** → ブランチ `dev` の最新 → **Visit** で開く URL をベースに、パスだけ足す（例: `/student/plan?tab=big`）。
  2. （任意）Vercel で **`dev` 専用の固定ドメイン**を割り当てている場合は、そのベース URL を **下の「固定プレビューURL」** に書いておき、毎回それ＋パスで渡す。

## どこで試すか

| 優先 | 環境 | URL / 手順 |
|------|------|------------|
| **推奨** | Vercel Preview（`dev`） | `dev` に push → Deployments の **Visit** URL ＋ パス（上記「固定プレビューURL」があればそれ＋パス） |
| 補助 | ローカル | `npm run dev` → `http://localhost:3000/...`（開発者向け・不安定になり得る） |
| 本番 | Production（`main`） | 本番ドメイン ＋ 同じパス |
